# BALOCHI DOCH EMBROIDERY — Handcrafted Traditional Balochi Dresses

A complete luxury e-commerce web application built with **React**, **Vite**, **TypeScript**, and **Tailwind CSS** (pure React, no shadcn).

---

## 🚀 How to Run in VS Code (VS Code me kaise run karein)

### Step 1: Extract & Open
1. ZIP file ko extract / unzip karein.
2. **VS Code** open karein aur `File -> Open Folder` se is extracted folder ko select karein.

### Step 2: Install Dependencies
VS Code me integrated terminal open karein (`Ctrl + ~` ya `Terminal -> New Terminal`) aur run karein:
```bash
npm install
```

### Step 3: Run Development Server
Local development server start karne k liye run karein:
```bash
npm run dev
```
Terminal me aapko local URL milega (usually `http://localhost:3000` ya `http://localhost:5173`). Browser me open karein!

---

## 🌐 How to Deploy (Deployment Instructions)

### Option 1: Deploy to Vercel (Easiest & Free)
1. Apne code ko GitHub repository me push karein.
2. [vercel.com](https://vercel.com) par jayein aur **Add New Project** select karein.
3. Apni repository import karein.
4. Framework Preset me **Vite** select hoga.
5. **Deploy** button dabayein — aapki website live ho jayegi!

### Option 2: Deploy to Netlify
1. Run karein:
```bash
npm run build
```
2. Netlify me jayein aur `dist` folder ko drag & drop karein ya GitHub se connect karein:
   - Build Command: `npm run build`
   - Publish Directory: `dist`

## 📁 10 Pages & Feature Structure

1. **HOME**: Hero banner matching Balochi Doch royal maroon & gold motif, trust pillars, featured collections, and "Art of Doch" story.
2. **SHOP / ALL PRODUCTS**: Complete catalog with live filters (Price slider, Colors: Maroon, Black, Gold, Fabrics: Cotton, Georgette, Silk, Velvet).
3. **DOCH COLLECTION**: Category-wise breakdown (Unstitched 3-Piece, Kurta & Tunics, Heavy Embroidery, Royal Bridal).
4. **PRODUCT DETAIL**: $128 USD / Rs. 35,000 PKR dual pricing, Hand-embroidered details, Mirror Work (Sheesha Doch), Add to Cart + Order on WhatsApp.
5. **OUR CRAFT / THE ART OF DOCH**: Baloch women artisans story, Mehrgarh 7000 BCE geometric patterns history, interactive motif decryption explorer.
6. **ABOUT US**: Heritage, fair-trade mission supporting Baloch artisans, transparency metrics.
7. **JOURNAL / BLOG**: "History of Balochi Embroidery", "How to Style Doch", and full reading mode.
8. **CONTACT**: Inquiry form, WhatsApp direct link, Quetta & Karachi atelier addresses and hours.
9. **CART + CHECKOUT**: Pakistan COD (Cash on Delivery Free) + International Shipping $15 (Free over $150).
10. **CUSTOMER CARE & SECURE TRACKING**: Shipping & Returns, Traditional Balochi Sizing Guide, FAQs, and a live Order Tracking portal with step-by-step artisan milestones.
